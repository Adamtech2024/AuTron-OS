# AuTron Operating System Series

## THIS OS IS OPEN SOURCE (ALWAYS WILL BE)

### AuTron OS is being rebuilt from the ground up.

The old version of this project has been archived for a few reasons:

- Not enough time to work on the OS
- Not enough developers to maintain it
- Not enough developers to make the OS look good and feel nice
- The only developer is busy

But this is not the end of AuTron OS.

The project is getting a completely new look, design and direction.

## AuTron 27 M

#### AuTron 27 M stands for AuTron 27 Minimal.

This version is made to use as little resources as possible while still having the important things you need.

It will include:

- Settings
- Chrome
- Simple drivers
- Notepad
- A LOT of optimization
- Other basic system features

The main goal is to keep AuTron 27 M as lightweight as possible.

## AuTron 27

### AuTron 27 is the main version of AuTron OS.

It will include:

- Settings
- Chrome
- Simple drivers
- Notepad
- Proper GUI, but still near text based
- Pixel-inspired UI
- Rounded corners and simple selection menus
- Full mouse and keyboard support
- Optimization
- More features and applications

AuTron 27 will be more complete than AuTron 27 M while still focusing on performance and simplicity.

Performance

AuTron OS is designed to be lightweight and fast.

The OS will focus on:

- Low RAM usage
- Low CPU usage
- Fast startup
- Low background resource usage
- Power efficiency
- Working well on older and lower-end hardware

The goal is to avoid using resources for things that are not needed.

## The Goal

The goal of AuTron OS is to make an operating system that is fast, simple, lightweight and nice to use.

The UI is designed to be simple enough to use with a keyboard, while also allowing everything to be selected with a mouse.

This is a completely new start for the project, so a lot of things can change during development.
